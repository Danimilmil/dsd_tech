# DSD TECH INSTALAÇÕES — Sistema de Recibos

Site estático: os recibos ficam salvos (criptografados) no navegador.

## Rodar localmente
```
cd dsd-recibos
npm install
npm start
```
Abra http://localhost:3000

## Deploy
Vercel (pasta de saída: `public`, sem build).

## Recursos
- Botão **SALVAR**: grava o recibo (criptografado) e já o mostra no Painel, sem recarregar a página.
